# Tablero Agencia TV — versión manual

Visor WebView exclusivo para:
https://tablero-agencia.onrender.com/

Pensado para TV Box Android 13 y Android TV. No incluye autoinicio: puede abrirse con una aplicación AutoStart externa.

## Compilar en Android Studio
1. Abrir esta carpeta como proyecto.
2. Esperar la sincronización de Gradle.
3. Build > Generate App Bundles or APKs > Generate APKs.
4. El APK queda en `app/build/outputs/apk/debug/` o `app/build/outputs/apk/release/`.
